# A Mini-CLI project

A Python project demonstrating logging, custom exception handling and file operations with pathlib.

## Setup & Installation

```bash
# 1. Create a virtual environment
python -m venv .venv
```

```bash
# 2. Activate virtual environment (Windows Powershell)
.venv/Scripts/Activate.ps1
```

```bash
# 3. Install the dependencies
pip install -r requirements.txt
```

## Runnign tests

```bash
python -m pytest
```
